<p class="wp-block-paragraph">A few years back I tried to find a way to communicate the scope of the ModVB project. After repeated attempts to edit the length down from hundreds of pages I decided to try a depth-first summary. This proved too expensive so I’m back going for a breadth-first approach. You know the adage “A picture is worth a thousand words”? I’m hoping that works with code samples. My goal here is for you to “see” the scale not necessarily the precision. I cannot condense 20 years of study into an elevator pitch, I’m sorry.</p>



<p class="wp-block-paragraph">So, I’m going to go through the outline and try to write as little prose as possible to illustrate what the change is. I’ll resist the urge to give context or backstory or motivation or exhaustively cover every bell and whistle but I will not if an idea feels less baked or there have been changes since I last publicly spoke on a topic. A few quick notes before we start to hopefully limit confusion in the comments.</p>



<ul class="wp-block-list">
<li>This is not a priority list; don’t @ me about where I should be focusing.</li>



<li>This is a list accumulated over 20 years of using VB.NET and/or 8 years developing it and investigating thousands of customer complaints and requests, etc. There is not much here that I haven’t thought about deeply so if it doesn’t make sense the fault is in the description, not the design. Back-compat, tooling, performance, etc., are all part of my process.</li>



<li>I don’t follow C# or F# language design, intentionally. I want to see VB actualized as the best it can be from its own intrinsic motivation, not copying the new shiny object from another language. There will be overlap in scenarios because they’re both general purpose languages and because I worked on both and had awareness of problems we wanted to solve since 2010 but I haven’t been keeping up with C# or F# since 2018 and have only a “feature name and snippet on Twittter” level of awareness of the depths of C# and F# additions. That said in the places where the features are analogous, of course there would be some reconciliation process to make for an acceptable interop story. It’s unlikely that I would accidentally overlook a chance to work well with the other languages.</li>



<li>This is not a release schedule. It’s not a project plan. It doesn’t include costs. That’s outside the scope of this document and will evolve on GitHub based on factors.</li>



<li>This doesn’t include the many IDE improvements I want to make.</li>



<li>Every section and most subsections have links for each referencing/sharing.</li>
</ul>

    animal.FlexBackbone()
    
    <span class="k">If</span> <span class="k">TypeOf</span> animal <span class="k">Is</span> <span class="t">Reptile</span> <span class="k">Then</span>
        animal.ShedScales()
        
        <span class="k">If</span> <span class="k">TypeOf</span> animal <span class="k">Is</span> <span class="t">Snake</span> <span class="k">Then</span>
            animal.Coil()
        <span class="k">End</span> <span class="k">If</span>
    <span class="k">End</span> <span class="k">If</span>
<span class="k">End</span> <span class="k">If</span></code></pre>

    animal.Fly()
<span class="k">End</span> <span class="k">If</span></code></pre>



<pre><code><span class="k">Let</span> animal <span class="k">As</span> <span class="t">Animal</span>? = SomeFunction()

<span class="c">' (Actual error text subject to change)</span>
<span class="c">' Error: `Move` is not a member of `Animal?`.</span>
<span class="c">' -OR-</span>
<span class="c">' Error: Cannot call member `Animal.Move` from nullable value.</span>
animal.Move()

<span class="k">If</span> animal <span class="k">IsNot</span> <span class="k">Null</span> <span class="k">Then</span>
    <span class="c">' No error.</span>
    animal.Move()
<span class="k">End</span> <span class="k">If</span></code></pre>



<pre><code><span class="c">' Works with guard statements (Return, Exit, Continue, Throw).</span>
<span class="k">If</span> <span class="k">TypeOf</span> animal <span class="k">IsNot</span> <span class="t">Mammal</span> <span class="k">Then</span> <span class="k">Return</span>
    
animal.ShedHair()</code></pre>



<pre><code><span class="c">' Monotremes are egg-laying mammals, including the Platypus and the Echidna.</span>
<span class="k">If</span> <span class="k">TypeOf</span> animal <span class="k">IsNot</span> <span class="t">Mammal</span> <span class="k">OrElse</span> animal.IsMonotreme <span class="k">Then</span>
    mayLayEggs = <span class="k">True</span>
<span class="k">End</span> <span class="k">If</span></code></pre>



<pre><code><span class="k">Let</span> animal <span class="k">As</span> <span class="t">Animal</span> = GetDolphin()

<span class="k">Do</span> <span class="k">Until</span> <span class="k">TypeOf</span> animal <span class="k">Is</span> <span class="t">ILandDwelling</span>
    <span class="c">' Or maybe I should have said:</span>
    <span class="c">' Do While TypeOf animal IsNot ILandDwelling?</span>
    animal = animal.GetImmediateAncestor()
<span class="k">Loop</span>

animal.Walk()</code></pre>



<pre><code><span class="k">Select</span> <span class="k">Case</span> <span class="k">TypeOf</span> dinosaur
    <span class="k">Case</span> <span class="k">IsNot</span> <span class="t">Bird</span>
        
        dinosaur.GoExtinct()
        
    <span class="k">Case</span> <span class="k">Else</span>
        <span class="c">' This metaphor is straining.</span>
        <span class="k">If</span> dinosaur.IsDodo <span class="k">Then</span>
            dinosaur.GoExtinct()
        <span class="k">Else</span>
            <span class="c">' Expensive O(n) lookup on Wikipedia.</span>
            
        <span class="k">End</span> <span class="k">If</span>
        
<span class="k">End</span> <span class="k">Select</span></code></pre>



<pre><code><span class="k">Let</span> usStateBearsByHibernationPeriod =
    <span class="k">From</span>
        state <span class="k">In</span> usStates
    <span class="k">Let</span>
        mammal = state.StateMammal
    <span class="k">Where</span>
        <span class="k">TypeOf</span> mammal <span class="k">Is</span> <span class="t">Bear</span> <span class="k">AndAlso</span> <span class="k">Not</span> mammal.IsExtinct
    <span class="k">Order By</span>
        mammal.HibernationPeriod <span class="k">Descending</span></code></pre>



<pre><code><span class="c">' In vanilla VB, type inference requires the 2nd &amp; 3rd operands</span>
<span class="c">' to convert to the type of one or the other or type inference</span>
<span class="c">' fails, resulting in type 'Object'.</span>
<span class="kv">Dim</span> animal = <span class="kv">If</span>(someCondition, <span class="kv">New</span> <span class="t">Cat</span>, <span class="kv">New</span> <span class="t">Dog</span>)</code></pre>



<pre><code><span class="c">' In ModVB, 'animal' would have type 'Carnivora',  which is the taxonomical</span>
<span class="c">' order common to cat-like and dog-like placental mammals, but that's not</span>
<span class="c">' actually useful because not all carnivorans are carnivores, e.g. bears</span>
<span class="c">' are often omnivores except for the Giant Panda which mostly eats plants.</span>
<span class="c">' So, even though it's inferred that type, the only members I can use are</span>
<span class="c">' defined on 'Mammal' in this example, which is still more than I could</span>
<span class="c">' use if the type were 'Object', so... </span>
<span class="k">Let</span> animal = <span class="k">If</span>(someCondition, <span class="k">New</span> <span class="t">Cat</span>, <span class="k">New</span> <span class="t">Dog</span>)
animal.SecreteMilk()</code></pre>



<pre><code><span class="c">' This should work.</span>
<span class="k">Let</span> snapshot = <span class="t">Snapshot</span>.Create()

<span class="c">' This should work correcly (infer the type of `cache`).</span>
<span class="k">Static</span> cache = <span class="k">New</span> <span class="t">Dictionary</span>(<span class="k">Of</span> <span class="k">Integer</span>, <span class="k">Integer</span>)

<span class="c">' Normally type-inference can't be done for a variable which</span>
<span class="c">' refers to itself (e.g. a recursive lambda expression).</span>
<span class="c">' But, since the types are explicit on the lambda,</span>
<span class="c">' technically type-inference is unnecessary; this should work.</span>
<span class="k">Let</span> factorial =
      <span class="k">Function</span>(n <span class="k">As</span> <span class="k">Integer</span>) <span class="k">As</span> <span class="k">Integer</span>
          <span class="k">If</span> n &lt; <span class="l">0</span> <span class="k">Then</span> <span class="k">Throw</span>
          
          <span class="k">Return</span> <span class="k">If</span>(n = <span class="l">0</span>, <span class="l">1</span>, n * factorial(n - <span class="l">1</span>))
      <span class="k">End</span> <span class="k">Function</span>

<span class="c">' Normally it's an error to refer to a variable before it's</span>
<span class="c">' declared (and also a definite assignment error).</span>
<span class="c">' Can these rules be relaxed in lambdas that aren't invoked</span>
<span class="c">' until all variables are declared and initialized to</span>
<span class="c">' enable mutual recursion?</span>
<span class="k">Let</span> isEven = <span class="k">Function</span>(n <span class="k">As</span> <span class="k">Integer</span>) <span class="k">As</span> <span class="k">Boolean</span>
                 <span class="k">Return</span> n = <span class="l">0</span> <span class="k">OrElse</span> isOdd(n - <span class="l">1</span>)
             <span class="k">End</span> <span class="k">Function</span>
             
<span class="k">Let</span> isOdd = <span class="k">Function</span>(n <span class="k">As</span> <span class="k">Integer</span>) <span class="k">As</span> <span class="k">Boolean</span>
                <span class="k">Return</span> n &lt;&gt; <span class="l">0</span> <span class="k">OrElse</span> isEven(n - <span class="l">1</span>)
            <span class="k">End</span> <span class="k">Function</span></code></pre>

<h3 class="wp-block-heading"><a href="#2.4-abbreviated-properties-events">2.4 New since summary published</a></h3>



<pre><code><span class="c">' Computed `ReadOnly` Properties.</span>
<span class="c">' Now 2 lines instead of 5.</span>
<span class="k">ReadOnly</span> <span class="k">Property</span> DiscountedPrice <span class="k">As</span> <span class="k">Decimal</span>
    <span class="k">Return</span> Price - (Price * DiscountRate)

<span class="c">' `Return` or `Get`?</span>
<span class="k">ReadOnly</span> <span class="k">Property</span> DiscountedPrice <span class="k">As</span> <span class="k">Decimal</span>
    <span class="k">Get</span> Price - (Price * DiscountRate)
    
<span class="c">' Accessor `End` Statements can be omitted.</span>
<span class="k">Property</span> Age <span class="k">As</span> <span class="k">Integer</span>
    <span class="k">Get</span>
        <span class="k">Return</span> _Age
        
    <span class="k">Set</span>(value)
        <span class="k">If</span> value &lt; <span class="l">0</span> <span class="k">Then</span> <span class="k">Throw</span>
            
        _Age = value
<span class="k">End</span> <span class="k">Property</span>

<span class="k">Event</span> AgeChanged <span class="k">As</span> <span class="t">EventHandler</span>
    <span class="k">AddHandler</span>(value)
        _AgeChanged += value
        
    <span class="k">RemoveHandler</span>(value)
        _AgeChanged -= value
    
    <span class="k">RaiseEvent</span>(sender, e)
        _AgeChanged?(sender, e)

<h2 class="wp-block-heading"><a href="#6-strings-pattern-matching">6. Strings and String Pattern Matching</a></h2>



<pre><code><span class="c">' This should only call String.Format once.</span>
? <span class="l">$"Greetings, &ZeroWidthSpace;</span>{firstName&ZeroWidthSpace;}<span class="l">. "</span> &amp;
  <span class="l">$"The current time is &ZeroWidthSpace;</span>{<span class="k">Date</span>.Now&ZeroWidthSpace;}<span class="l">, "</span> &amp;
  <span class="l">$"on &ZeroWidthSpace;</span>{<span class="k">Date</span>.Today.DayOfWeek&ZeroWidthSpace;}<span class="l">."</span>

<span class="c">' This shouldn't call String.Format at all.</span>
<span class="k">Throw</span> <span class="k">New</span> <span class="t">ArgumentNullException</span>(
            description, 
            <span class="l">$"Argument '&ZeroWidthSpace;</span>{<span class="k">NameOf</span>(description)}<span class="l">' may not be null."</span>
          )

<span class="c">' `&amp;=` should work whether concatenating a string variable or a StringBuilder.</span>
<span class="k">Let</span> builder <span class="k">As</span> <span class="t">StringBuilder</span> = ...
builder &amp;= <span class="l">"Line"</span> &amp; vbCrLf

<span class="c">' String pattern matching (inverse of interpolation).</span>
<span class="k">Select</span> <span class="k">Case</span> <span class="k">ShapeOf</span> command
    <span class="k">Case</span> <span class="l">$"/echo &ZeroWidthSpace;</span>{message&ZeroWidthSpace;}<span class="l">"</span>
        
        ? message
        
    <span class="k">Case</span> <span class="l">$"/beep &ZeroWidthSpace;</span>{frequency <span class="k">As</span> <span class="k">Integer</span>}<span class="l"> &ZeroWidthSpace;</span>{duration <span class="k">As</span> <span class="k">Integer</span>}<span class="l">"</span>
        
        Console.Beep(frequency, duration \ <span class="l">1000</span>)
        
    <span class="k">Case</span> <span class="l">"/clear"</span>
        
        Console.Clear()

    <span class="k">Case</span> <span class="k">Else</span>
        ? <span class="l">"Unrecognized command: "</span> &amp; command

<span class="k">End</span> <span class="k">Select</span></code></pre>



<pre><code><span class="c">' Narrowing conversion operator from String if Parse exists.</span>
<span class="k">Let</span> nil <span class="k">As</span> <span class="t">Guid</span> = <span class="l">"00000000-0000-0000-0000-000000000000"</span>

<span class="k">Let</span> str = <span class="l">"20.0.255.255:23"</span>

<h2 class="wp-block-heading"><a href="#7-general-pattern-matching">7. General Pattern Matching</a></h2>



<pre><code><span class="c">' Explicit and implicit `ShapeOf` operators.</span>
<span class="k">Select</span> <span class="k">Case</span> <span class="k">ShapeOf</span> input
  <span class="k">Case</span> pn <span class="k">As</span> <span class="t">USPhoneNumber</span>
    <span class="k">Return</span> <span class="k">New</span> <span class="t">DomesticContact</span>(pn)
  
  <span class="k">Case</span> pn <span class="k">As</span> <span class="t">InternationalPhoneNumber</span> 
    <span class="k">Return</span> <span class="k">New</span> <span class="t">GlobalContact</span>(pn)
    
<span class="k">End</span> <span class="k">Select</span>

<span class="c">' User-defined pattern methods.</span>
<span class="k">Let</span> hasAnotherChar =
      <span class="k">Function</span>(reader <span class="k">As</span> <span class="t">TextStream</span>, <span class="k">Out</span> ch <span class="k">As</span> <span class="k">Char</span>) <span class="k">As</span> <span class="k">Boolean</span>
          <span class="k">If</span> reader.EndOfFile() <span class="k">Then</span>
              <span class="k">Return</span> <span class="k">False</span>, ch:=<span class="k">Nothing</span>
          <span class="k">Else</span>
              <span class="k">Return</span> <span class="k">True</span>, ch:=reader.PeekChar(<span class="l">0</span>)
          <span class="k">End</span> <span class="k">If</span>
      <span class="k">End</span> <span class="k">Function</span>

<span class="k">If</span> <span class="k">ShapeOf</span> stream <span class="k">Is</span> hasAnotherChar(c) <span class="k">AndAlso</span> c &lt;&gt; <span class="k">Nothing</span> <span class="k">Then</span>
    buffer.Append(c)
    stream.EatNextChar()
<span class="k">End</span> <span class="k">If</span>
</code></pre>



<pre><code><span class="c">' Named patterns.</span>
<span class="k">Function</span> ConstructorCall(
           node <span class="k">As</span> <span class="t">ExecutableStatementSyntax</span>,
           <span class="k">Out</span> kind <span class="k">As</span> <span class="t">VBSyntaxKind</span>,
           <span class="k">Out</span> arguments <span class="k">As</span> <span class="t">SeparatedSyntaxList</span>(<span class="k">Of</span> <span class="t">ArgumentSyntax</span>)
         )
         <span class="k">As</span> <span class="k">Boolean</span>

    <span class="c">' Bring shared pattern functions into scope.</span>
    <span class="k">Imports</span> SyntaxPatterns

    <span class="c">' Deconstruction syntax matches/inverts factory syntax.</span>
    <span class="k">Select</span> <span class="k">Case</span> <span class="k">ShapeOf</span> node
      <span class="c">' MyBase.New(...)</span>
      <span class="k">Case</span> ExpressionStatement(
             InvocationExpression(
               MemberAccess(
                 MeExpression(),
                 IdentifierName(<span class="l">"New"</span>)
               ),
               argList
             )
           )
       
        <span class="k">Return</span> <span class="k">True</span>, kind:=VBSyntaxKind.MeExpression,
                     arguments:=argList.Arguments

      <span class="c">' Me.New(...)</span>
      <span class="k">Case</span> ExpressionStatement(
             InvocationExpression(
               MemberAccess(
                 MyBaseExpression(),
                 IdentifierName(<span class="l">"New"</span>)
               ),
               argList
             )
           )

        <span class="k">Return</span> <span class="k">True</span>, kind:=VBSyntaxKind.MyBaseExpression,
                     arguments:=argList.Arguments

      <span class="k">Case</span> <span class="k">Else</span>

        <span class="k">Return</span> <span class="k">False</span>, kind:=<span class="k">Nothing</span>, arguments:=<span class="k">Nothing</span>
      
    <span class="k">End</span> <span class="k">Select</span>
<span class="k">End</span> <span class="k">Function</span>

<span class="c">' Check if first statement of constructor is</span>
<span class="c">' a call to another constructor.</span>
<span class="k">Let</span> firstStatement <span class="k">As</span> <span class="t">ExecutableStatementSyntax</span> = ...

<span class="k">If</span> <span class="k">ShapeOf</span> firstStatement <span class="k">Is</span> ConstructorCall(kind, args) <span class="k">Then</span>
    <span class="k">If</span> kind = VBSyntaxKind.MeExpression <span class="k">Then</span>
        ProcessChainedConstructorCall(args)
        
    <span class="k">ElseIf</span> kind = VBSyntaxKind.MyBaseExpression <span class="k">Then</span>
        ProcessBaseConstructorCall(args)
        
    <span class="k">End</span> <span class="k">If</span>
<span class="k">Else</span>
    ProcessOtherStatement(firstStatement)
   
<span class="k">End</span> <span class="k">If</span></code></pre>



<h2 class="wp-block-heading"><a href="#8-modernization-declarations">8. General Modernization and Evolution II (Declarations)</a></h2>



<pre><code><span class="c">' `Out` arguments avoid null-reference warnings, and</span>
<span class="c">' allow for inference and implicit declaration of variables.</span>
<span class="k">If</span> cache.TryGetValue(name, <span class="k">Out</span> value) <span class="k">Then</span>
    <span class="k">Return</span> value
<span class="k">End</span> <span class="k">If</span>

<span class="c">' Explicit `ByRef` argument syntax for clarity, stricter checking,</span>
<span class="c">' and disambiguation when needed.</span>
ReportErrors(<span class="k">ByRef</span> diagnostics)

<span class="c">' `Out` parameters for idiomatic multiple returns (e.g. pattern methods).</span>
<span class="k">Function</span> IsPerfectSquare(number <span class="k">As</span> <span class="k">Integer</span>, <span class="k">Out</span> root <span class="k">As</span> <span class="k">Integer</span>) <span class="k">As</span> <span class="k">Boolean</span>
    
    <span class="k">Select</span> <span class="k">Case</span> number
        <span class="k">Case</span> <span class="l">1</span>
            <span class="c">' Simplified single-statement return with `Out` assigns.</span>
            <span class="k">Return</span> <span class="k">True</span>, root:=<span class="l">1</span>
            
        <span class="k">Case</span> <span class="l">4</span>
            <span class="k">Return</span> <span class="k">True</span>, root:=<span class="l">2</span>
            
        <span class="k">Case</span> <span class="l">9</span>        
            <span class="k">Return</span> <span class="k">True</span>, root:=<span class="l">3</span>

        <span class="k">Case</span> <span class="k">Else</span>
            <span class="k">Let</span> intRoot <span class="k">As</span> <span class="k">Integer</span> = <span class="t">Math</span>.Sqrt(number)

            <span class="k">If</span> (intRoot * intRoot) = number <span class="k">Then</span>
                <span class="k">Return</span> <span class="k">True</span>, root:=intRoot
            <span class="k">Else</span>
                <span class="k">Return</span> <span class="k">False</span>, root:=<span class="k">Nothing</span>
            <span class="k">End</span> <span class="k">If</span>
    <span class="k">End</span> <span class="k">Select</span>
<span class="k">End</span> <span class="k">Function</span>    

<span class="c">' Modules may be generic, nested, and won't hoist members</span>
<span class="c">' into containing namespace by default.</span>
<span class="k">Module</span> <span class="t">Utils</span>(<span class="k">Of</span> <span class="t">T</span>)
    ...
    <span class="k">Module</span> <span class="t">Strings</span>
        ...

<span class="c">' Classic behavior can be opted into with attribute.</span>
&lt;<span class="t">StandardModule</span>&gt;
<span class="k">Module</span> <span class="t">IOHelpers</span>
    ...

<span class="c">' Namespaces, Shared type members, and XML/JSON namespaces can</span>
<span class="c">' be imported at the method level.</span>
<span class="k">Sub</span> WriteHelp()
    <span class="k">Imports</span> System.<span class="t">Console</span>
    <span class="k">Imports</span> &lt;xmlns:xs=<span class="l">"http://www.w3.org/2001/XMLSchema"</span>&gt;

    Clear()    
    WriteLine(<span class="l">"..."</span>)
    WriteLine(<span class="l">"..."</span>)

<span class="k">End</span> <span class="k">Sub</span>

<span class="c">' Bit modifier for &lt;Flags&gt; Enums.</span>
<span class="k">Bit</span> <span class="k">Enum</span> <span class="t">MyFlags</span> <span class="k">As</span> <span class="k">Byte</span>
    None
    
    <span class="c">' Correct initialization by default</span>
    First  <span class="c">' = 1</span>
    Second <span class="c">' = 2</span>
    Third  <span class="c">' = 4</span>
    Fourth <span class="c">' = 8</span>
    
    <span class="c">' Simpler masks.</span>
    Odds = First, Third
    Evens = Second, Fourth
    All = Odds, Evens

    <span class="c">' Named numeric sections.    </span>
    Kind = <span class="k">Bit</span> <span class="l">4</span> <span class="k">To</span> <span class="k">Bit</span> <span class="l">7</span>
<span class="k">End</span> <span class="k">Enum</span>

<span class="k">Let</span> flags <span class="k">As</span> <span class="t">MyFlags</span> = &amp;B_0111_1010

<h2 class="wp-block-heading"><a href="#12-null-nothing-nullable-reference-types">12. Null and Nothing</a></h2>

<pre><code><span class="c">' `Null` literal for null-references and values.</span>

<span class="c">' null-propagation from `?.` for</span>
<span class="c">' the following statements/operators:</span>

<h2 class="wp-block-heading"><a href="#13-declarative-programming-source-generation">13. Declarative Programming and Code-Generation</a></h2>



<p class="wp-block-paragraph">These strategies make different trade-offs in end-developer experience, tool-author experience, performance, complexity, etc. The same scenario might be addressed using more than one approach or a combination. <h3 class="wp-block-heading"><a href="#13.1-smart-attributes">13.1 Smart Attributes – Declarative w/o Source Generators</a></h3>



<p class="wp-block-paragraph">This approach prioritizes simplicity.</p>

                             sender <span class="k">As</span> <span class="k">Object</span>,
                             propertyName <span class="k">As</span> <span class="k">String</span>,
                             <span class="k">ByRef</span> backingField <span class="k">As</span> <span class="t">T</span>,
                             <span class="k">ByRef</span> value <span class="k">As</span> <span class="t">T</span>
                           ) <span class="k">As</span> <span class="k">Boolean</span>

        <span class="k">Return</span> (value ?= backingField)
    <span class="k">End</span> <span class="k">Sub</span>
<span class="k">End</span> <span class="k">Class</span>

<span class="k">Public</span> <span class="k">Class</span> <span class="t">AutoRoundAttribute</span>
    <span class="k">Inherits</span> <span class="t">PropertyHandlerAttribute</span>

    <span class="k">Sub</span> <span class="k">New</span>(digits <span class="k">As</span> <span class="k">Integer</span>)
        <span class="c">' Because this constructor arguments are copied to the generated callsite,</span>
        <span class="c">' the 'digits' parameter doesn't actually have to be saved anywhere.</span>
        <span class="k">Do</span> <span class="k">Nothing</span>
    <span class="k">End</span> <span class="k">Sub</span>

    <span class="k">Public</span> <span class="k">Shared</span> <span class="k">Sub</span> OnPropertySet(
                        sender <span class="k">As</span> <span class="k">Object</span>,
                        propertyName <span class="k">As</span> <span class="k">String</span>,
                        <span class="k">ByRef</span> backingField <span class="k">As</span> <span class="k">Decimal</span>,
                        <span class="k">ByRef</span> value <span class="k">As</span> <span class="k">Decimal</span>,
                        digits <span class="k">As</span> <span class="k">Integer</span>
                      )

        value = Math.Round(value, digits)
    <span class="k">End</span> <span class="k">Sub</span>
<span class="k">End</span> <span class="k">Class</span>
#<span class="k">End</span> <span class="k">Region</span>

<span class="k">Public</span> <span class="k">Class</span> <span class="t">ThrowOnNullAttribute</span>
    <span class="k">Inherits</span> <span class="t">PropertyHandlerAttribute</span>

    <span class="k">Public</span> <span class="k">Shared</span> <span class="k">Sub</span> OnPropertySet(sender <span class="k">As</span> <span class="k">Object</span>,
                                    propertyName <span class="k">As</span> <span class="k">String</span>,
                                    backingField <span class="k">As</span> <span class="k">Object</span>,
                                    value <span class="k">As</span> <span class="k">Object</span>)

        <span class="k">If</span> value <span class="k">Is</span> <span class="k">Nothing</span> <span class="k">Then</span> <span class="k">Throw</span> <span class="k">New</span> <span class="t">ArgumentNullException</span>(propertyName)
    <span class="k">End</span> <span class="k">Sub</span>
<span class="k">End</span> <span class="k">Class</span>

<span class="k">Public</span> <span class="k">Class</span> <span class="t">UndoableAttribute</span>
    <span class="k">Inherits</span> <span class="t">PropertyHandlerAttribute</span>

    <span class="k">Public</span> <span class="k">Shared</span> <span class="k">Sub</span> OnPropertySet(obj <span class="k">As</span> <span class="k">Object</span>,
                                    propertyName <span class="k">As</span> <span class="k">String</span>,
                                    previousValue <span class="k">As</span> <span class="k">Object</span>,
                                    <span class="k">ByRef</span> newValue <span class="k">As</span> <span class="k">Object</span>)

        UndoRedo.Remember(<span class="k">Sub</span>() CallByName(obj, propertyName, CallType.Set, previousValue))
    <span class="k">End</span> <span class="k">Sub</span>
<span class="k">End</span> <span class="k">Class</span>

<span class="k">Class</span> <span class="t">NotSupportedAttribute</span>
    <span class="k">Inherits</span> <span class="t">PropertyHandlerAttribute</span>

    <span class="k">Shared</span> <span class="k">Sub</span> OnPropertyGet(<span class="k">Of</span> <span class="t">T</span>)(obj <span class="k">As</span> <span class="k">Object</span>,
                                   propertyName <span class="k">As</span> <span class="k">String</span>,
                                   <span class="k">ByRef</span> backingField <span class="k">As</span> <span class="t">T</span>,
                                   <span class="k">ByRef</span> value <span class="k">As</span> <span class="t">T</span>)

        <span class="k">Throw</span> <span class="k">New</span> <span class="t">NotSupportedException</span>(propertyName)
    <span class="k">End</span> <span class="k">Sub</span>

    <span class="k">Shared</span> <span class="k">Sub</span> OnPropertySet(<span class="k">Of</span> <span class="t">T</span>)(obj <span class="k">As</span> <span class="k">Object</span>,
                                   propertyName <span class="k">As</span> <span class="k">String</span>,
                                   <span class="k">ByRef</span> backingField <span class="k">As</span> <span class="t">T</span>,
                                   <span class="k">ByRef</span> value <span class="k">As</span> <span class="t">T</span>)

        <span class="k">Throw</span> <span class="k">New</span> <span class="t">NotSupportedException</span>(propertyName)
    <span class="k">End</span> <span class="k">Sub</span>
<span class="k">End</span> <span class="k">Class</span></code></pre>



<h3 class="wp-block-heading"><a href="#13.2-source-member-replacement">13.2 New Replacement Modifiers – Declarative w/ Source Generators</a></h3>



<p class="wp-block-paragraph">This is approach is all about conversational collaboration between an end-developer and source generation tools.</p>



<p class="wp-block-paragraph"><code>Replaceable</code> and <code>Replaces</code> Modifiers</p>



<p class="wp-block-paragraph">Analogous to <code>Overridable</code> and <code>Overrides</code> modifiers. Another source member declaration can replace this one.</p>



<p class="wp-block-paragraph"><strong>Human-to-Tool</strong></p>



<p class="wp-block-paragraph">e.g. Human writes algorithm semantics naturally and tool <s>mutilates</s> optimizes it for performance.</p>



<pre><code><span class="c">' Handwritten.vb</span>
&lt;<span class="t">Optimize</span>&gt;
<span class="k">Replaceable</span> <span class="k">Function</span> ToCommaSeparated(
                       items <span class="k">As</span> <span class="t">IEnumerable</span>(<span class="k">Of</span> <span class="k">Object</span>)
                     )
                     <span class="k">As</span> <span class="k">String</span>

    <span class="k">Let</span> firstItem = items.FirstOrDefault()?
    
    <span class="k">If</span> firstItem <span class="k">Is</span> <span class="k">Null</span> <span class="k">Then</span> <span class="k">Return</span> <span class="l">""</span>

    <span class="k">Let</span> result = firstItem.ToString()        
        
    <span class="k">For</span> <span class="k">Each</span> item <span class="k">In</span> items <span class="k">Skip</span> <span class="l">1</span>
        result &amp;= <span class="l">", "</span> &amp; item.ToString()
    <span class="k">Next</span>
    
    <span class="k">Return</span> result.ToString()
<span class="k">End</span> <span class="k">Function</span></code></pre>



<pre><code><span class="c">' ToolGenerated.vb</span>
<span class="k">Replaces</span> <span class="k">Function</span> ToCommaSeparated(
                    items <span class="k">As</span> <span class="t">IEnumerable</span>(<span class="k">Of</span> <span class="k">Object</span>)
                  )
                  <span class="k">As</span> <span class="k">String</span>
                     
    <span class="k">If</span> <span class="k">TypeOf</span> items <span class="k">Is</span> <span class="k">Object</span>() <span class="k">Then</span>
        <span class="c">' Array fast-path doesn't allocate enumerator</span>
        <span class="c">' for array and indexing is faster anyway.</span>
        <span class="k">Select</span> <span class="k">Case</span> items.Length
          <span class="k">Case</span> <span class="l">0</span>
              <span class="c">' Don't do anything for an empty collection.</span>
              <span class="k">Return</span> <span class="k">String</span>.Empty
          <span class="k">Case</span> <span class="l">1</span>
              <span class="c">' For array of 1, simply return its `ToString()`.</span>
              <span class="k">Return</span> items(<span class="l">0</span>).ToString()
          <span class="k">Case</span> <span class="k">Else</span>
              <span class="c">' Allocate `StringBuilder` as last resort.</span>
              <span class="k">Let</span> builder = <span class="k">New</span> <span class="t">StringBuilder</span>(items.Length * <span class="l">4</span>)
              
              builder.Append(items(<span class="l">0</span>).ToString())
              
              <span class="k">For</span> i = <span class="l">1</span> <span class="k">To</span> builder.Length - <span class="l">1</span>
                <span class="c">' Don't concat then append;</span>
                <span class="c">' append twice.</span>
                  builder.Append(<span class="l">", "</span>)
                  builder.Append(items(i).ToString())
              <span class="k">Next</span>
              
              <span class="k">Return</span> builder.ToString()
        <span class="k">End</span> <span class="k">Select</span>
    <span class="k">Else</span>
        <span class="k">Using</span> enumerator = items.GetEnumerator()
            <span class="c">' Don't do anything for an empty collection.</span>
            <span class="k">If</span> <span class="k">Not</span> enumerator.MoveNext() <span class="k">Then</span> <span class="k">Return</span> <span class="k">String</span>.Empty

            <span class="k">Let</span> firstItem = enumerator.Current
            
            <span class="c">' For collection of 1, simply return its `ToString()`.</span>
            <span class="k">If</span> <span class="k">Not</span> enumerator.MoveNext() <span class="k">Then</span> <span class="k">Return</span> firstItem.ToString()

            <span class="c">' Allocate `StringBuilder` as last resort.</span>
            <span class="k">Let</span> builder = <span class="k">New</span> <span class="t">StringBuilder</span>(firstItem.ToString())
              
            <span class="k">Do</span>
                <span class="c">' Don't concat then append;</span>
                <span class="c">' append twice.</span>
                builder.Append(<span class="l">", "</span>)
                builder.Append(enumerator.Current.ToString())
            <span class="k">Loop</span> <span class="k">While</span> enumerator.MoveNext()
              
            <span class="k">Return</span> builder.ToString()
        <span class="k">End</span> <span class="k">Using</span>
    <span class="k">End</span> <span class="k">If</span>
<span class="k">End</span> <span class="k">Function</span></code></pre>



<p class="wp-block-paragraph"><strong>Human-to-Tool-to-Human</strong></p>



<p class="wp-block-paragraph">e.g. Tool provides default implementation which human tweaks for correctness. Note the conversational back-and-forth.</p>



<p class="wp-block-paragraph">The developer requests boilerplate serialization logic:</p>



<pre><code><span class="c">' Handwritten.vb - Step 1.</span>
<span class="k">Class</span> <span class="t">Student</span>
    
    <span class="k">Property</span> StudentId <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> LastName <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> FirstName <span class="k">As</span> <span class="k">String</span>
        
<span class="k">End</span> <span class="k">Class</span>

&lt;<span class="t">Xmlifiable</span>&gt;
<span class="k">Class</span> <span class="t">AthleticsTeam</span>
    
    <span class="k">Property</span> Sport <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> School <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> Coach <span class="k">As</span> <span class="k">String</span>
    <span class="k">ReadOnly</span> <span class="k">Property</span> Players <span class="k">As</span> <span class="k">New</span> <span class="t">List</span>(<span class="k">Of</span> <span class="t">Student</span>)
    
<span class="k">End</span> <span class="k">Class</span></code></pre>



<p class="wp-block-paragraph">The tool responds with its best guess based on conventions:</p>



<pre><code><span class="c">' ToolGenerated.vb - Step 2.</span>
<span class="k">Partial</span> <span class="k">Class</span> <span class="t">AthleticsTeam</span>

    <span class="k">Replaceable</span> <span class="k">Function</span> ToXml() <span class="k">As</span> <span class="t">XElement</span>
        &lt;Team&gt;
          &lt;School&gt;School&lt;/&gt;
          &lt;Sport&gt;Sport&lt;/&gt;
          &lt;Coach&gt;Coach&lt;/&gt;
          &lt;Players&gt;
            <span class="k">For</span> <span class="k">Each</span> student <span class="k">In</span> Players
                <span class="k">Yield</span> ToXml(student)
            <span class="k">Next</span>
          &lt;/Players&gt;
        &lt;/Team&gt;
    <span class="k">End</span> <span class="k">Function</span>
    
    <span class="k">Replaceable</span> <span class="k">Shared</span> <span class="k">Function</span> ToXml(student <span class="k">As</span> <span class="t">Student</span>) <span class="k">As</span> <span class="t">XElement</span>
        &lt;Student&gt;
          &lt;StudentId&gt;student.StudentId&lt;/&gt;
          &lt;LastName&gt;student.LastName&lt;/&gt;
          &lt;FirstName&gt;student.FirstName&lt;/&gt;
        &lt;/Student&gt;
    <span class="k">End</span> <span class="k">Function</span>
    
<span class="k">End</span> <span class="k">Class</span></code></pre>



<p class="wp-block-paragraph">And the human tweaks only what they need to:</p>



<pre><code><span class="c">' Handwritten.vb - Step 3.</span>
<span class="k">Class</span> <span class="t">Student</span>
    
    <span class="k">Property</span> StudentId <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> LastName <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> FirstName <span class="k">As</span> <span class="k">String</span>
        
<span class="k">End</span> <span class="k">Class</span>

&lt;<span class="t">Xmlifiable</span>&gt;
<span class="k">Class</span> <span class="t">AthleticsTeam</span>
    
    <span class="k">Property</span> Sport <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> School <span class="k">As</span> <span class="k">String</span>
    <span class="k">Property</span> Coach <span class="k">As</span> <span class="k">String</span>
    <span class="k">ReadOnly</span> <span class="k">Property</span> Players <span class="k">As</span> <span class="k">New</span> <span class="t">List</span>(<span class="k">Of</span> <span class="t">Student</span>)

    <span class="c">' Tweaks the default (generated) implementation of</span>
    <span class="c">' serializing a student without losing the benefit</span>
    <span class="c">' of the generated boilerplate logic for the team.</span>
    <span class="k">Replaces</span> <span class="k">Shared</span> <span class="k">Function</span> ToXml(student <span class="k">As</span> <span class="t">Student</span>) <span class="k">As</span> <span class="t">XElement</span>
        &lt;Player id-number={student.StudentId}&gt;
          &lt;FullName&gt;student.LastName &amp; <span class="l">", "</span> &amp; student.FirstName&lt;/&gt;
        &lt;/Player&gt;
    <span class="k">End</span> <span class="k">Function</span>
    
<span class="k">End</span> <span class="k">Class</span></code></pre>



<p class="wp-block-paragraph"><code>MustReplace</code> Modifier</p>



<p class="wp-block-paragraph">Analogous to <code>MustOverride</code> modifier and P/Invoke <code>Declare</code> statements. The specified name and signature must be supplied by another source member declaration.</p>



<p class="wp-block-paragraph"><strong>Human-to-Tool-to-Human</strong></p>



<p class="wp-block-paragraph">Developer declares a need:</p>



<pre><code><span class="c">' Handwritten.vb - Step 1.</span>
&lt;<span class="t">StoredProcedure</span>(<span class="l">"Customers_SelectByCity"</span>)&gt;
<span class="k">MustReplace</span> <span class="k">Function</span> GetCustomersByCity(city <span class="k">As</span> <span class="k">String</span>) <span class="k">As</span> <span class="t">List</span>(<span class="k">Of</span> <span class="k">String</span>)</code></pre>



<p class="wp-block-paragraph">Tool supplies the need but declares a need of its own:</p>



<pre><code><span class="c">' ToolGenerated.vb - Step 2.</span>
<span class="k">MustReplace</span> <span class="k">Function</span> CreateConnection() <span class="k">As</span> <span class="t">DbConnection</span>

<span class="k">Replaces</span> <span class="k">Function</span> GetCustomersByCity(city <span class="k">As</span> <span class="k">String</span>) <span class="k">As</span> <span class="t">List</span>(<span class="k">Of</span> <span class="k">String</span>)
    <span class="k">Using</span> connection = CreateConnection()
        <span class="k">With</span> command = connection.CreateCommand()
            .CommandType = <span class="t">CommandType</span>.StoredProcedure
            .CommandText = <span class="l">"Customers_SelectByCity"</span>
            
            <span class="k">With</span> .CreateParameter()
                .ParameterName = <span class="l">"@city"</span>
                .DbType = <span class="t">DbType</span>.String
                .Value = city
                
                command.Add(.Me)
            <span class="k">End</span> <span class="k">With</span>
            
            connection.Open()
            <span class="k">Using</span> reader = .ExecuteReader()
                <span class="k">Let</span> results = <span class="k">New</span> <span class="t">List</span>(<span class="k">Of</span> <span class="k">String</span>)
                        
                <span class="k">Do</span> <span class="k">While</span> reader.Read()
                    results.Add(reader.GetString(<span class="l">0</span>))
                <span class="k">Loop</span>
                connection.Close()
                
                <span class="k">Return</span> results
            <span class="k">End</span> <span class="k">Using</span>
        <span class="k">End</span> <span class="k">With</span>
    <span class="k">End</span> <span class="k">Using</span>
<span class="k">End</span> <span class="k">Function</span></code></pre>



<p class="wp-block-paragraph">Developer supplies what tool needs to fulfill initial request:</p>



<pre><code><span class="c">' Handwritten.vb - Step 3.</span>
&lt;<span class="t">StoredProcedure</span>(<span class="l">"Customers_SelectByCity"</span>)&gt;
<span class="k">MustReplace</span> <span class="k">Function</span> GetCustomersByCity(city <span class="k">As</span> <span class="k">String</span>) <span class="k">As</span> <span class="t">List</span>(<span class="k">Of</span> <span class="k">String</span>)

<span class="k">Replaces</span> <span class="k">Function</span> CreateConnection() <span class="k">As</span> <span class="t">DbConnection</span>
    <span class="k">Return</span> <span class="k">New</span> <span class="t">SqlConnection</span>(
                 ConfigurationManager.ConnectionStrings!AcmeDb.ConnectionString
               )
<span class="k">End</span> <span class="k">Function</span></code></pre>



<p class="wp-block-paragraph"><code>NotReplaceable</code> Modifier</p>



<p class="wp-block-paragraph">Analogous to <code>NotOverridable</code> modifier. The provided implementation must not be replaced. Only useful if the final design includes that certain kinds of declarations are replaceable by default (i.e. auto-implemented properties and events).</p>



<h3 class="wp-block-heading"><a href="#13.3-partial-members">13.3 <code>Partial</code> members</a></h3>



<p class="wp-block-paragraph"><code>Partial</code> Modifier</p>



<p class="wp-block-paragraph">Can now be applied to any type member, regardless of access modifiers. All partial metadata merged. Useful for adding attributes, documentation comments, <code>Handles</code>, <code>Implements</code>, <code>Overrides</code> clauses to an existing member in another file.</p>



<pre><code><span class="c">' `End Sub` no longer required for `Partial` subs.</span>
<span class="k">Partial</span> <span class="k">Sub</span> OnModelLoaded()
<span class="c">' End Sub</span></code></pre>



<h3 class="wp-block-heading"><a href="#13.4-semantic-pre-processing">13.4 Semantic Pre-Processing</a></h3>



<p class="wp-block-paragraph">This capability is highly depending on the performance of certain analyzer or source generator techniques. But the versioning/cross-plat scenario has been a pain for a while.</p>



<pre><code><span class="c">' Conditionally compile statements.</span>

<span class="c">' Enables better code-sharing (e.g. shared projects/linked-files)</span>
<span class="c">' and cross-platform "adaptive light-up".</span>
<span class="k">Let</span> obj <span class="k">As</span> <span class="t">MyType</span> = ...

##<span class="k">If</span> METHOD_EXISTS(obj.BetterMethod) <span class="k">Then</span>
    obj.BetterMethod(...)
##<span class="k">Else</span>
    <span class="c">' Must call obsolete method in this case.</span>
    #<span class="k">Ignore</span> <span class="k">Warning</span> BC40008
    obj.OldSlowMethod(...)
##<span class="k">End</span> <span class="k">If</span>

<span class="c">' Conditionally compile declarations.</span>

<span class="c">' Enables source generation from syntax w/o requiring semantic</span>
<span class="c">' analysis.</span>
##<span class="k">If</span> TYPE_EXISTS(System.DateTimeOffset) <span class="k">Then</span>
    <span class="k">Sub</span> WriteLine(value <span class="k">As</span> <span class="t">DateTimeOffset</span>)
        ...
    <span class="k">End</span> <span class="k">Sub</span>
##<span class="k">End</span> <span class="k">If</span>

<span class="c">' Enables source generators to provide boilerplate if missing.</span>

<span class="c">' ToolGenerated.vb</span>
<span class="k">Partial</span> <span class="k">Class</span> <span class="t">MyViewModel</span>
    <span class="k">Implements</span> <span class="t">INotifyPropertyChanged</span>

    <span class="c">' Only declare this if the end-developer didn't.</span>
    ##<span class="k">If</span> <span class="k">Not</span> MEMBER_EXISTS(PropertyChanged) <span class="k">Then</span>
        <span class="k">Event</span> PropertyChanged <span class="k">As</span> <span class="t">PropertyChangedEventHandler</span>
    ##<span class="k">End</span> <span class="k">If</span>

<span class="k">End</span> <span class="k">Class</span>

##<span class="k">If</span> MEMBER_EXISTS(OnNameChanged) <span class="k">Then</span>
    OnNameChanged()

##<span class="k">ElseIf</span> MEMBER_EXISTS(OnPropertyChanged) <span class="k">Then</span>
    OnPropertyChanged(<span class="l">"Name"</span>)

##<span class="k">Else</span>
    <span class="c">' Derived types can't raise base class events!</span>
    <span class="k">RaiseEvent</span> PropertyChanged(<span class="k">Me</span>, <span class="k">New</span> <span class="t">PropertyChangedEventArgs</span>(<span class="l">"Name"</span>))
##<span class="k">End</span> <span class="k">If</span>

<span class="c">' Enables project templates/source generators to detect</span>
<span class="c">' errors or provide warnings.</span>

##<span class="k">If</span> ... <span class="k">Then</span>
    #<span class="k">Warning</span> <span class="l">"Behavior may be different on this platform. Did you mean to target .NET 11?"</span>
##<span class="k">End</span> <span class="k">If</span>

##<span class="k">If</span> <span class="k">Not</span> TYPE_EXISTS(...) <span class="k">Then</span>
    #<span class="k">Warning</span> <span class="l">"Types from 'MyAssembly' required at runtime via reflection. Add a reference to ensure binary is deployed on build."</span>
##<span class="k">End</span> <span class="k">If</span>

##<span class="k">If</span> <span class="k">Not</span> MEMBER_EXISTS(...) <span class="k">Then</span>
    #<span class="k">Error</span> <span class="l">"Must define a deserialization constructor."</span>

<p class="wp-block-paragraph">Ok, so one day I hear an F# dev lament the lack of early returns in functional expressions. So, as I do, I thought <em>“How would I write this code in ModVB?”</em> and here’s what I came up with:</p>



<pre><code><span class="k">Function</span> GetIVsTextView() <span class="k">As</span> <span class="t">IVsTextView</span>

    <span class="k">If</span> <span class="k">TypeOf</span> rdt <span class="k">IsNot</span> <span class="t">IVsRunningDocumentTable</span> <span class="k">Then</span> <span class="k">Return</span> <span class="k">Null</span>
        
    <span class="k">Let</span> hresult = FindAndLockDocument(rdt, <span class="k">Out</span> docData <span class="k">As</span> <span class="t">IntPtr</span>)
    <span class="k">If</span> <span class="k">Not</span> <span class="t">ErrorHandler</span>.Succeed(hresult) <span class="k">Then</span> <span class="k">Return</span> <span class="k">Null</span>
    <span class="k">If</span> docData = <span class="t">IntPtr</span>.Zero <span class="k">Then</span> <span class="k">Return</span> <span class="k">Null</span>
        
    <span class="k">Let</span> textBuffer = <span class="t">Marshal</span>.GetObjectForIUnknown(docData)

<span class="k">End</span> <span class="k">Function</span></code></pre>



<p class="wp-block-paragraph">This was oppressively monotonous and I started thinking about simplifying with tuples and nullability or <code>Out</code> variables and anything I could think of to break the boring pattern. I knew I didn’t like the <code>if let</code>/<code>guard let</code> syntax in other languages (e.g. Swift) because it doesn’t read naturally to me. Eventually I realized I was actually cool with the concept, I just didn’t like that syntax and came up with this to eliminate a lot of duplication:</p>

    ...

<span class="c">' e.g.</span>

    ...

    ...

<span class="c">' still an open question, though.</span>
<span class="k">Let</span> address = <span class="k">New</span> <span class="t">Address</span>
<span class="k">If</span> <span class="k">ShapeOf</span> json <span class="k">IsNot</span> {
     <span class="l">"line1"</span>: address.Street
     <span class="l">"line2"</span>: <span class="k">null</span>,
     <span class="l">"city"</span> : address.City
     <span class="l">"state"</span>: address.State
   }
<span class="k">Then</span>
    <span class="k">Throw</span> <span class="k">New</span> <span class="t">DeserializationFailureException</span>()
<span class="k">End</span> <span class="k">If</span>

<span class="k">Return</span> address

</code></pre>



<h3 class="wp-block-heading">18.8 VB Idiomatic custom JSON serializers</h3>



<p class="wp-block-paragraph">This goes with the previous example. The only scenario I consistently hear for “ref structs” is custom JSON serializers with <code>Utf8JsonReader</code>. Setting aside the general issue, this assumes that the idiomatic way to write a deserializer in VB is the way it’s done in C#. I could delay, mitigate, or side-step the issue if VB had a natural abstraction for this.</p>



<h3 class="wp-block-heading">18.9 More elegant integration of case-insensitivity/collation</h3>



<p class="wp-block-paragraph">VB has many built-in constructs that may compare strings:</p>



<ul class="wp-block-list">
<li>Comparison operators <code>=</code>, <code>&lt;&gt;</code>, <code>&lt;</code> , <code>&gt;</code>, <code>&lt;=</code>, <code>&gt;=</code> in binary expressions.</li>



<li>The same in <code>Select Case</code> blocks.</li>
</ul>



<p class="wp-block-paragraph">Many applications benefit from case-insensitive string comparisons but this means not using the built-in support for strings, which is a hallmark of BASIC since time immemorial.</p>



<p class="wp-block-paragraph">You can use <code>Option Compare Text</code> but it has unexpected null handling and only affects comparison operators and <code>Select Case</code> and certain APIs in the VB runtime library (if you’ve ever wonder how that works–it’s basically <code>&lt;CallerOptionCompareSettingAttribute&gt;</code>). And this doesn’t include the <code>Distinct</code> query operator at all. This means giving up the syntactic sugar and calling <code>Equals</code> and passing <code>ComparisonType</code> or <code>StringComparer</code>.</p>



<p class="wp-block-paragraph">This issue becomes worse with String and JSON pattern matching. An elegant solution that integrates with existing .NET APIs would be wonderful. There are some starting places for investigating such as design but it needs more consideration.</p>



<h3 class="wp-block-heading">18.10 Lookahead and backtracking in String patterns</h3>



<p class="wp-block-paragraph">As-is pattern-matching evaluates patterns from the outside to the inside, left to right. This raises several problems:</p>



<ul class="wp-block-list">
<li>A naïve implementation of String pattern matching would allocate many needless intermediate garbage strings.</li>



<li>Certain common patterns need backtracking.</li>



<li>Inner patterns can’t influence decomposition of the outer pattern and lazy or greedy ways.</li>
</ul>



<p class="wp-block-paragraph">It would be good in the design of the string pattern matching to consider how the feature would apply to a text window/stream or a span.</p>



<h3 class="wp-block-heading">18.11 String vs Span/ReadOnlySpan(Of Char/Byte) and UTF-8</h3>



<p class="wp-block-paragraph">String handling in VB must be awesome! We cannot allow modern problems to introduce ugliness into our codebases.</p>



<h3 class="wp-block-heading">18.12 Named pattern inputs</h3>



<p class="wp-block-paragraph">Some hypothetical patterns would benefit from additional “inputs” (e.g. <code>Regex("\d+", n)</code>) but currently the “argument” list for a named pattern is output only. This should be investigated.</p>



<h3 class="wp-block-heading">18.13 Patterns as data?</h3>



<p class="wp-block-paragraph">Composition is essential to managing complexity but as-is there isn’t yet a way to pass patterns around as data or compose them. Fixing this could open some scenarios.</p>



<h3 class="wp-block-heading">18.14 PLINQ, Async queries, more query operators</h3>



<p class="wp-block-paragraph">Parallel LINQ, queries that use <code>Await</code>, queries against <code>IAsyncEnumerable</code> are areas to investigate. As query languages and data stores evolve we also have to ensure that the query comprehension syntax can smoothly express common use-cases (e.g. Common-Table Expressions, Geospatial data, No-SQL, Temporal Databases) without needing to fallback to extension methods and lambda expressions.</p>



<h3 class="wp-block-heading">18.15 New ConfigureAwait options/fire-and-forget exception handling</h3>



<p class="wp-block-paragraph">Void-returning async methods are my white whale. I must find more ways to limit their spread. Additionally when “forgetting” a Task-returning async method I need to be sure folks can express/configure the various patterns to unobserved exceptions.</p>



<h3 class="wp-block-heading">18.16 “Nullable Reference Types”</h3>



<p class="wp-block-paragraph">Nullable Reference Types has received mix reviews in C#. And VB users have expressed confusion and concern about how it would be done in VB. I consider it a failure if users hate the new feature turn it off or advise others to do so. I must refine the design to consider these observations.</p>



<h3 class="wp-block-heading">18.17 Handling duplicate declarations, “File” accessibility, “Appendable” methods?</h3>



<p class="wp-block-paragraph">Source generator authoring (and performance) could be negatively impacted trying to avoid name clashes, duplicate definitions (or ensuring there aren’t). I’ve thought through some ways to handle this at various layers.</p>



<p class="wp-block-paragraph">I personally dislike stitching together statements from across multiple files into one method. I don’t want two VB script files to just run back-to-back or for end-developers to have to think too hard about the order partial files would be combined in. With that said, a source generator analog to a “multicast delegate” could impact how certain scenarios are addressed between my various declarative programming approaches.</p>



<h3 class="wp-block-heading">18.18 Generative compiler scripting</h3>



<p class="wp-block-paragraph">I’m pretty sure this is a bad idea. But at some point I’ll venture into that dragon’s lair.</p>



<h3 class="wp-block-heading">18.19 Units of Measure?</h3>



<p class="wp-block-paragraph">When F# debuted with many cool ideas. I like the feeling of units of measure but I’m not convinced it’s a no-brainer. I’ve gone through several exercises to see how a VB user might implement a unit of measure system in a library without language support at all, or, what the minimal set of features could be added to make the experience of creating and using such a system acceptable. I will continue to investigate but so far my exercises have yielded 1 uncontroversial feature: <strong>Generic Operators</strong>.</p>



<p class="wp-block-paragraph">There is an attractive syntactic sugar that isn’t necessary but would clean up some rough edges, e.g. <code>Weight(in lbs)</code> but exploring the space is absolutely worth a dedicated and detailed in-depth posting.</p>



<h3 class="wp-block-heading">18.20 Annotated types/Type flavors</h3>



<p class="wp-block-paragraph">In Visual Studio 2008 VB introduced XML literals. The VB team had a feature for providing IntelliSense for XML elements and attributes in the code editor based on schema files:</p>

Additionally, now with a greater emphasis on JSON a similar IntelliSense experience for examining JSON payloads in the editor is a no-brainer. Given some context the IDE should be able to provide a list of completions when you type <code>jsonObject!</code></p>



<p class="wp-block-paragraph">To support this experience I’ve already mentioned a desire to make XML and JSON schema types expressible in code, even if just decoration:</p>



<pre><code><span class="c">' Suggestions should be provided after typing `order.&lt;`.</span>
<span class="k">Sub</span> ProcessOrder(order <span class="k">As</span> &lt;PurchaseOrder&gt;)

<span class="c">' Suggestions should be provided after typing `request!`.</span>
<span class="k">Sub</span> ProcessRequest(request <span class="k">As</span> {<span class="l">"trade-message"</span>})</code></pre>



<p class="wp-block-paragraph">These don’t have to be realized as their own types (in fact it’s better if they aren’t) but more of an annotation on e.g. <code>XElement</code> or <code>JsonObject</code> that tools can use.</p>



<p class="wp-block-paragraph">And we do something like this today with tuple types–<code>(x As Integer, y As Integer)</code> doesn’t generate a new type but annotates the declaration in such a way as to surface those names on <code>ValueTuple(Of Integer, Integer)</code>.</p>



<p class="wp-block-paragraph">C# does basically the same thing to represent <code>dynamic</code> which is otherwise represented as <code>System.Object</code> within the .NET runtime. And ModVB will do the same with the <code>Any</code> type.</p>



<p class="wp-block-paragraph">What if simple anonymous delegate types e.g. unified with <code>Action</code> and <code>Func</code> types instead of generating their own anonymous ones, e.g. <code>&lt;Function(Object) As Boolean&gt;</code> is a flavor of  <code>Func(Of Object, Boolean)</code>. VB already does some magic to erase those types if ultimately converted to a nominal delegate type. Then VB users could use <code>Action</code> and <code>Func</code> types while still surfacing valuable information to callers:</p>



<pre><code><span class="c">' Do you know what the two parameters to the delegate mean?</span>
<span class="k">Function</span> ReplaceNodes(
           nodes <span class="k">As</span> <span class="t">IEnumerable</span>(<span class="k">Of</span> <span class="t">Node</span>),
           replacer <span class="k">As</span> <span class="t">Func</span>(<span class="k">Of</span> <span class="t">Node</span>, <span class="t">Node</span>, <span class="t">Node</span>)

         <span class="k">As</span> <span class="t">Node</span>

<span class="k">Function</span> ReplaceNodes(
           nodes <span class="k">As</span> <span class="t">IEnumerable</span>(<span class="k">Of</span> <span class="t">Node</span>),

         )
         <span class="k">As</span> <span class="t">Node</span></code></pre>



<p class="wp-block-paragraph">And then there’s the aforementioned units-of-measure question, what if it were tracked as an annotation on a numeric variable rather than a real type?</p>



<p class="wp-block-paragraph">Funny story: Once Erik Meijer (who was a significant influence on VB9) told me that the way the XML IntelliSense was done was actually essentially “type provider”, at least for the purposes of filing a patent on it. Which brings me to my final scenario:</p>



<p class="wp-block-paragraph">Type Providers.</p>



<p class="wp-block-paragraph">Ok, not the compile-time code generation/injection approach used in F# but something a little less … trusting of 3rd party code running inside the compiler. I haven’t landed on an intuitive syntax but imagine if a developer could annotate any type reference in code with some arbitrary metadata which tools could use to provide suggestions and diagnostics!</p>



<pre><code><span class="c">' Annotated with the key for a connection string.</span>

db.StoredProcedures!sp_DeleteOldRecords()   
   
<span class="k">Let</span> api = <span class="k">New</span> <span class="t">RestProxy</span>(<span class="k">For</span> <span class="l">"api.github.com"</span>)()

? api.HttpGet(<span class="l">"/repos/..."</span>)

<span class="c">' As easy as late-binding but not actually.</span>

wmi.Classes!Win32_Process.Methods!Create(commandLine:=<span class="l">"notepad.exe"</span>,
                                         returnValue:=<span class="k">Out</span> code <span class="k">As</span> <span class="t">UInt32</span>)
<span class="k">If</span> code = <span class="l">0</span> <span class="k">Then</span>
    ...</code></pre>

<h3 class="wp-block-heading">18.22 Overloading on <code>Structure</code> constraint</h3>



<p class="wp-block-paragraph">Sometimes when dealing with generics, I wish I could provide different implementations for value types and reference types especially when any kind of nullability is involved. But you can’t overload methods on generic constraints. But there’s a cheat.</p>



<pre><code><span class="c">' (As we all know...) you can't overload on generic constraints.</span>
<span class="c">' This is illegal:</span>
<span class="k">Sub</span> M(<span class="k">Of</span> <span class="t">T</span> <span class="k">As</span> <span class="k">Class</span>)(p <span class="k">As</span> <span class="t">T</span>)
<span class="k">Sub</span> M(<span class="k">Of</span> <span class="t">T</span> <span class="k">As</span> <span class="k">Structure</span>)(p <span class="k">As</span> <span class="t">T</span>)

<span class="c">' But this is not:</span>
<span class="k">Sub</span> M(<span class="k">Of</span> <span class="t">T</span> <span class="k">As</span> <span class="k">Class</span>)(p <span class="k">As</span> <span class="t">T</span>)
<span class="k">Sub</span> M(<span class="k">Of</span> <span class="t">T</span> <span class="k">As</span> <span class="k">Structure</span>)(p <span class="k">As</span> <span class="t">T</span>, <span class="k">Optional</span> ignored <span class="k">As</span> <span class="k">Object</span> = <span class="k">Nothing</span>)

<span class="c">' Because VB considers type parameter constraints in determining</span>
<span class="c">' which overloads are applicable, these lines do what you'd hope:</span>
M(<span class="l">""</span>) <span class="c">' Calls reference type overload.</span>
M(<span class="l">1</span>)  <span class="c">' Calls value type overload</span></code></pre>



<p class="wp-block-paragraph">So this is a “to-do” to consider how to remove the need for the fake parameter in source even if it needs there in the metadata. That’s it.</p>

If I wanted to spend the rest of my 40s trying to prove things to some unknown judge my anxiety has created. But this is like years of work and it won’t all come out in one release and there’s a lot of work to do. This “one-pager” represents probably 80% of the compiler/language possibilities that I’m motivated to pursue in ModVB. But that’s only like 65% of the total project. The other 35% is IDE stuff, etc. And on top of that there’s broader <a href="https://github.com/openvbdotnet">OpenVB community</a>/organization/foss stuff that the entire VB community needs to be part of.  This is not “a product” or “a release” or “some features”. It’s a living programming language community and everything that entails on an ongoing basis without a defined end-point.</p>



<p class="wp-block-paragraph">I hope this document gives people a sense that the future of VB isn’t about “catching up” to some other perceived front-runner. It’s not about feature envy or re-styling the things other communities are focusing on but finding and maintaining our own focus on what our community has to offer and can become.</p>



<p class="wp-block-paragraph">And this all lives in my head all the time and I’d like to get it out of there. So, I’m going to trust my audience to trust me. And respect me, and my time, my ideas, and focus on making cool things and stop selling myself and selling the idea that there are cool things worth making. Thanks for reading.</p>



<p class="wp-block-paragraph">Regards,</p>



<p class="wp-block-paragraph"><strong>-Anthony D. Green</strong></p>
