# VBScript.NET 1.0 已实现特性归档（done）

本目录仿照 csharplang 的 `proposals/csharp-<版本>/` 惯例，归档**已随 VBScript.NET 发布版本实现并定稿**的语法提案（done 档）。

## 归档规则

- **判入标准**：特性已在 VBScript.NET 某个发布版本中实现并写入规范（对应 LDM 判定 Active 且 `Implementation`/`Specification` 进度完成）。
- **目录命名**：`proposals/vbscript-<版本>/`（当前为 `vbscript-1.0/`，随首个发布版本沿用/改名）。
- **当前成员**：无——VBScript.NET 尚未发布任何特性到正式版本。
- **会议纪要**：done 提案的会议纪要归档到 `meetings/vbscript-<版本>/`（同步创建）。

## 说明

- 本目录为**机制占位**（`proposals/README.md` 四类模型中的「done」档）。
- 未实现的提案不在本目录：设计定稿未发布 → 留在根目录（active）；搁置/未定型 → `inactive/`；否决 → `rejected/`。
